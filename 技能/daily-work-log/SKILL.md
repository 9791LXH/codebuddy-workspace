## 工作表结构

文件包含多个工作表，按月份命名：`6月份`、`5月份 `、`4月份` 等（注意部分名称有尾随空格）。

写入时根据日期所属月份自动匹配工作表。

## 写入规则（重要）

**新增记录必须紧跟同日期已有记录的下方**，保持同一天的记录连续排列。

**⚠️ 查找插入位置的核心逻辑**：

```
# ❌ 错误做法：直接用 max_row（可能因中间空白行导致错误位置）
insert_row = ws.max_row + 1

# ✅ 正确做法：从 max_row 向上找到最后一个有数据的行
last_data_row = ws.max_row
while last_data_row > 0 and ws.cell(row=last_data_row, column=1).value is None:
    last_data_row -= 1
insert_row = last_data_row + 1
```

**步骤**：

1. 从 `ws.max_row` 向上扫描，找到 A 列最后一个非空行作为基准行
2. 在基准行的**下一行**追加数据（无需 insert_rows，直接写入即可）
   - 若基准行与当天日期相同，直接追加在其下方
   - 若基准行是更早的日期，也直接追加在其下方（新日期紧跟旧日期）
3. 日期列写入 Excel 序列号（整数），不写文本

## 写入流程

### 1. 解析用户口述内容

将口述内容整理为以下字段：
- **日期**：从上下文判断（"今天"、"6月5日"等），转为 `YYYY-MM-DD`
- **维度**：根据内容判断类别
  - `日常工作`：设备、订单、客户、售后、研发等
  - `学习培训`：培训班、课程、讲座等
  - `出差外勤`：出差、拜访客户、现场等
  - `部门协助`：协助其他部门工作
  - `会议`：各类会议
- **具体内容**：一句话标题，10字以内
- **处理过程**：完整描述，保留关键细节
- **结果成效**：**需完善填写**，尽量补充成果和影响力，不要留空
- **个人总结**：**试着以用户口吻代写心得感悟**，不要留空

### 2. 调用写入脚本

使用 `scripts/write_log.py`（需要 `openpyxl`）：

```bash
python "C:/Users/lu551/.workbuddy/skills/daily-work-log/scripts/write_log.py" \
  "2026-06-05" "学习培训" "苏州工匠培育班" "上午AI+产业经济，下午AI落地实践，晚上手机视频拍剪" "" ""
```

或直接用 Python 内联写入（参考脚本逻辑）。

### 3. 一天多条记录

如果用户口述包含多个不同事项，分别写入多行，每行一个事项。

### 4. 写入后确认

写入成功后，告知用户：
- 写入日期、维度、内容摘要
- 写入位置（第几行、哪个工作表）
- 询问是否补充"结果成效"或"个人总结"

## 定时提醒流程（每天17:00触发）

每天下午5点自动触发，执行以下步骤：

1. 发送提醒：`📝 下班时间到！今天工作了什么？请简单说一下今天的重点工作内容，我来帮你整理写入每日重点回顾表。`
2. 等待用户回复
3. 按上述流程整理并写入 Excel
4. 确认写入完成

## 日期序列号换算参考

Excel 序列号以 `1899-12-30` 为基准（第0天）：

| 日期 | 序列号 |
|------|--------|
| 2026-06-01 | 46173 |
| 2026-06-05 | 46177（注：46176=2026-06-03，依此类推）|

计算方式：`(目标日期 - date(1899,12,30)).days`
